소요 시간

예상 1분

How · 캐시 키 전략

잠금 파일 해시로 캐시를 고정했다

cache:
  key:
    files: [Cargo.lock, rust-toolchain.toml]   # 해시가 곧 캐시 키
  paths: [~/.cargo/registry, target/]
  policy: pull-push                            # 히트 시 pull, 갱신 시 push
build:
  script:
    - cargo build --locked --offline || cargo build --locked
    - sccache --show-stats                     # 원격 캐시 적중률 확인

핵심은 결정적 키 — 잠금 파일이 안 바뀌면 캐시를 그대로 재사용한다.

요지

캐시 무효화 규칙만 제대로 잡으면 대부분 해결된다.

핵심

  • key.files 해시가 결정적 — 같은 잠금 파일 = 같은 캐시
  • --offline 우선, 실패 시 폴백

Q&A 대비

  • 캐시 오염? — pull-push + 해시 키로 격리
