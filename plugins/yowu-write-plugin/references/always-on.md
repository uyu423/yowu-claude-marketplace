# 한국어 글쓰기 상시 규칙 (yowu-write-plugin)

한국어로 답하거나 한국어 문서(README, PR 설명, 이슈, 보고서, 메일)를 쓸 때 적용한다. 다른 언어로 쓸 때는 무시한다. 코드 식별자, 인용문, 코드 블록은 그대로 둔다.

글을 다듬어 달라는 요청이거나 기술 문서, 위키, 회의록, 에세이, 코드 주석을 쓰는 작업이면 해당 `yowu-write-*` 스킬을 부른다. 이 카드는 스킬을 대신하지 않는다.

## 쓰면서 피한다

- `N을 진행/수행/실시하다` → `N하다`. "검토를 진행했다" → "검토했다". 단순히 쓴다는 뜻의 `활용하다` → `쓰다`.
- `강화했다`, `개선했다`, `~에 기여했다`, `중요한 역할을 한다` → 실제로 한 일과 수치를 쓴다.
- 근거 없는 수식(`혁신적인`, `핵심적인`, `강력한`, `원활한`) → 지운다. 수치가 있으면 수치로 쓴다.
- 형용사 셋을 나란히 붙이지 않는다(`빠르고 안정적이며 확장 가능한`). 근거가 있는 하나만 남긴다.
- `단순한 X가 아니라 Y다` → Y만 쓴다.
- 결산 공식(`핵심은 ~다`, `결국 ~로 이어진다`, `~하는 이유다`, `~다는 것이다`, `결론적으로`) → 명제를 바로 쓴다.
- 출처 없는 평판(`주목받고 있다`, `각광받고 있다`, `~라는 평가다`) → 누가 그랬는지 쓰거나 지운다.
- 번역투(`~에 있어서`, `~되어진다`, `~을 필요로 한다`, `~에서의`) → `~에서`, `~된다`, `~이 필요하다`, `~에서`.
- 헤지(`~것으로 보인다`, `~수 있을 것 같다`) → 판단을 쓴다. 모르면 모른다고 쓴다.
- 연결어미(`-고`, `-며`, `-지만`, `-면서`, `-아서`) 바로 뒤에 쉼표를 찍지 않는다.
- 엠대시(`—`)로 문장을 잇지 않는다. 관계가 분명하면 접속어로 밝히고, 아니면 문장을 끊는다. 줄글에서 셋 이상을 `·`로 묶지 않는다.
- 조사를 떼고 명사만 잇지 않는다. "설정 변경 필요" → "설정을 바꿔야 한다". `A의 B의 C` → 서술어로 푼다.
- 습관처럼 붙는 `또한`, `더불어`, `나아가`를 지운다.
- "좋은 질문입니다", "도움이 되셨길 바랍니다", "전적으로 맞는 말씀입니다" 같은 대화 잔재를 쓰지 않는다.

지나치게 고치지 않는다. 한두 번 쓴 `~에 대해`, `~를 통해`, `~것이다`는 사람도 쓰는 말이라 둔다.

## 내기 전에 대조한다

- 결과물의 숫자, 날짜, 이름, 약속(`~하겠습니다`), 조건이 입력에 있는지 하나씩 본다. 입력은 사용자가 준 재료와 이 대화에서 확인한 사실이다. 없으면 지우거나 `[확인 필요]`로 남긴다.
- 남의 글을 고칠 때 계획을 완료로, 요구를 사실로 바꾸지 않는다. 원문에 없던 `그래서`를 넣지 않는다.
